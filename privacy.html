Privacy policy

Last updated: 8 October 2026

This policy covers "Job search mail helper", a personal tool used only by its owner, Abdullah Yawari, with his own Google account (abdullah.yawari046@gmail.com).

What the tool accesses

  • gmail.send: lets the tool send emails that the owner has written. It cannot read, search, change or delete any email.
  • openid and email: lets the tool confirm which Google account signed in. It accepts only the owner's account and refuses any other.

What the tool stores

  • The sign-in token from Google is stored only on the owner's own computer, encrypted with the Windows Data Protection API. It is never sent anywhere except to Google.
  • To stop the same email from being sent twice, the tool keeps a short local log on the owner's computer for each sent email: date, recipient, subject, Gmail message ID, and the attached file's name and checksum.
  • Attachments come only from the owner's own files on his computer. The tool reads no Gmail content, so it stores none.

Sharing

When the owner sends an email, the message and its attachments go through Google (Gmail) to the recipients he chose. The tool shares nothing else with anyone, and it does not sell or transfer any data. It has no advertising and no analytics, and nobody else uses it.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. The owner can also delete the stored token from his computer.
